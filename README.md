|---------|----------|

# 4. Установка и настройка

Создание бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Введите имя бота (например: "IThub Valentine Bot")
4. Введите username бота (например: "ithub_valentine_bot")
5. Скопируйте полученный токен

## 4.3 Получение ID администратора

1. Откройте [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте любое сообщение
3. Скопируйте ваш ID

## 4.4 Настройка конфигурации

Отредактируйте файл `config.py`:

```python
BOT_TOKEN = "123456789:ABCdefGHIjklMNOpqrsTUVwxyz"
ADMIN_IDS = [123456789, 987654321]
NOTIFY_ADMINS_ON_VIOLATION = True
```

## 4.5 Запуск

```bash
python main.py
```

# 7. Описание модулей

## 7.1 main.py

**Назначение:** Точка входа приложения, инициализация и запуск бота.

```python
import asyncio
import logging
from aiogram import Bot, Dispatcher
from aiogram.fsm.storage.memory import MemoryStorage

from handlers import router
import config

logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s'
)

async def main():
    bot = Bot(token=config.BOT_TOKEN)
    storage = MemoryStorage()
    dp = Dispatcher(storage=storage)
    dp.include_router(router)
    
    logging.info("💕 Бот валентинок запущен!")
    await dp.start_polling(bot)

if __name__ == "__main__":
    asyncio.run(main())
```

{

| Поле | Тип | Описание |

## 8.2 valentines.json

**Назначение:** Хранение отправленных валентинок.

### Структура:

```json
{
  "recipient_username": [
    {
      "from": "sender_username",
      "from_id": 123456789,
      "message": "Текст валентинки",
      "is_anonymous": false,
      "is_read": false,
      "sent_at": "2024-02-14T12:00:00"
    },
    {
      "from": "Аноним 🎭",
      "from_id": null,
      "message": "Анонимная валентинка",
      "is_anonymous": true,
      "is_read": true,
      "sent_at": "2024-02-14T13:00:00"
    }
  ]
}
```

### Поля валентинки:

| Поле | Тип | Описание |
|------|-----|----------|
| `from` | string | Username отправителя или "Аноним 🎭" |
| `from_id` | int/null | ID отправителя (null для анонимных) |
| `message` | string | Текст валентинки |
| `is_anonymous` | boolean | Анонимная ли валентинка |
| `is_read` | boolean | Прочитана ли валентинка |
| `sent_at` | string (ISO) | Дата и время отправки |

## 12.2 Обходы фильтра (защита)

Система защищает от следующих попыток обхода:

| Попытка обхода | Пример | Как обрабатывается |
|----------------|--------|-------------------|
| Замена букв символами | "дур@к" | @ → а |
| Замена кириллицы латиницей | "дyрак" | y → у |
| Цифры вместо букв | "дур4к" | 4 → ч |
| Повторение букв | "дуууурак" | → "дурак" |
| Пробелы внутри слова | "д у р а к" | Удаляются |
| Символы внутри слова | "д.у.р.а.к" | Удаляются |

## Деплой через Docker

### Откройте файл ИНСТРУКЦИЯ

Частые проблемы

### Проблема: Бот не отвечает

**Причины:**
1. Неверный токен
2. Бот не запущен
3. Ошибка в коде

**Решение:**
```bash
# Проверить логи
sudo journalctl -u valentine-bot -f

# Проверить токен
python -c "import config; print(config.BOT_TOKEN[:10])"
```

### Проблема: Ошибка "AttributeError: 'int' object has no attribute 'get'"

**Причина:** Несовместимый формат данных в users.json

**Решение:**
- Удалить файл users.json и перезапустить бота
- Или обновить функцию `get_all_users()` для поддержки обоих форматов

### Проблема: Уведомления не приходят

**Причины:**
1. Получатель заблокировал бота
2. Получатель не использовал бота ранее

**Решение:**
- Проверить users.json на наличие получателя
- Попросить получателя написать /start боту

### Проблема: Модерация не работает

**Причины:**
1. Файл bad_words.py не импортирован
2. Слово написано не в нижнем регистре

**Решение:**
```python
# Проверить импорт
from bad_words import BAD_WORDS
print(BAD_WORDS)

# Проверить регистр слов
assert all(w.islower() for w in BAD_WORDS)
```
